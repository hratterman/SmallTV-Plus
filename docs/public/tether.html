SmallTV tether

Lends this computer's internet connection to the cube, over the USB cable.

This browser can't do it.

Talking to a serial port from a page needs the Web Serial API, which today means Chrome, Edge or Opera on desktop. Safari and Firefox haven't implemented it. Open this same page in one of those and the button below will work.

This page needs to be served over HTTPS.

Browsers only expose serial ports to secure pages. Opening the file straight from disk may or may not count, depending on the browser's rules — the hosted copy always does.

Cube settings

Read from the cube over the same cable, and written back the same way — this is the identical settings file the built-in web page edits. Fields are generated from whatever the firmware sends, so nothing here can fall out of step with it. Passwords and tokens are never sent out by the cube; leave those blank to keep what is stored.

What works over the cable

A page can only fetch what the far end allows it to (CORS), so this is not everything the cube can do on a normal network:

  • Spotify — fully, including album art.
  • Clock — taken from this computer, so no time server is needed.
  • Ticker — set your symbols to the GitHub source. Yahoo blocks browser requests.
  • Radar — not available; adsb.fi blocks browser requests too.
