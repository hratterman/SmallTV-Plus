Set up

Three steps and the cube is online:

  1. Plug the cube's USB cable into this computer.
  2. Press Connect and pick the USB entry in the list (it may be called "CP2102", "CH340" or "USB Serial" — that's the cube).
  3. That's it. The cube borrows this computer's internet while the page stays open.
Tip: install this page as an app (button above, when offered) and put it in your login items — then the cube comes online whenever the computer does.

Calendar over the cable

The secret iCal link cannot be read by this page directly — the providers block scripts from it. Two ways around that:

Your browser may download what scripts may not read: open the secret link, and a .ics file lands in Downloads. Hand it over and the cube shows the next two days from it.

Or make the link itself work: a 10-line Google bridge

Google's own Apps Script serves pages a browser may read. Paste this at script.google.com (New project), put your secret link in, then Deploy → New deployment → Web app, access: Anyone. Use the deployment URL as the cube's calendar link — it then updates itself over the cable, no file dropping.

The deployment URL is a capability like the secret link itself: whoever holds it can read the calendar. Treat both the same.

Firmware update

A cube that lives on this cable never joins WiFi, so this is how it gets updates: drop the firmware.bin here and it flashes over the cable — about three minutes. The cube keeps its old firmware until the new one arrives whole, so a pulled cable is a do-over, not a brick.
